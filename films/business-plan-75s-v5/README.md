# Final Final Studio — Business Plan film / V5 structural motion revision

Complete **75-second** film for **Yiran Wang**, **Media Business & Enterprise**. Delivery is **1920 × 1080**, **30 fps**, **2,250 frames**, H.264/AAC with Rec.709 colour metadata. The canvas has no persistent corner branding, chapter labels, page numbers, timecodes or debug text. The final brand card is static from exactly 72.000 to 75.000 seconds.

## Play

For the exported film, double-click **watch.html** after extracting the ZIP, or open the included MP4 directly. This uses the native video player and needs no video-editor installation. If browser policy blocks local HTML files, run the server below and open `/watch.html`; local file navigation is blocked in this execution environment, so native playback was verified through that HTTP route.

For the editable live composition, Node.js is sufficient. From this project directory:

```sh
node server.cjs
```

Open the served index.html. Its controls, chapters and JSON editor are outside the rendered film. Play starts the original music and action effects; sound can be muted. The HTTP server supports video byte ranges for accurate scrubbing. If port8000 is occupied, run `PORT=8001 npm start`.

The exported film is `output/FinalFinalStudio-BusinessPlan-75s-v5.mp4`. A complete MP4 is also included in the delivery ZIP so the preview download button works after extraction. Preview and movie playback need no external asset or font requests.

Rendering needs FFmpeg and Chromium. Install a browser with `npx playwright install chromium` or point `CHROMIUM_PATH` at a system Chromium. The exact Playwright dependency is locked. The renderer samples the live composition at30fps, seeks the actual product video for each frame, and mixes the provided music/effects master without any speech.

`node render.cjs --range 25:35` renders an optional local inspection segment; the normal render always produces the complete75seconds. The renderer preserves failure exit status and writes FFmpeg logs under output/.

- **config.js**: all principal copy, proposed prices, chapter boundaries, colours and media/sound paths. Service and brand names retain natural capitalization.
- **engine.js**: editable vector/type, mask, video-crop, graphic and input primitives; source-video clocks and simple colour treatment.
- **objects.js**: type-free layered paper, hinged swatches, film strips, contact shadows, crop marks, cutting tools and path rails. `G.layer` skips retired text layers completely; `G.retire` defines frame-based opacity and geometry gates.
- **chapters.js**: author intro, request-to-brand choreography, client inputs, promise, filename and final card. Detailed word/path timing is editable here.
- **services.js**: actual service demonstrations, package quantities, prices, capped monthly planning and project process. Detailed choreography is editable here.
- **watch.html**: installation-free native playback of the actual included full MP4.
- **index.html**: playable full-film composition, frame slider and configuration editor. Applying JSON changes affects the current preview; save it into config.js to keep changes.
- **assets/beat-map.json**: actual120BPM music beats and action effects with exact time/frame markers. Source audio is generated by scripts/make_audio.py; NumPy is needed only to regenerate it.

The main chapter boundaries in config.js describe the delivery timing. To retime choreography, also update the relevant phase boundaries in chapters.js/services.js and source-video clocks in engine.js, then regenerate the audio/cue map and render again.

## V5: text lifetime and connected object design

The previous input transformation coupled the document lettering to the shrinking card. The new scene draws its paper geometry and lettering in separate layers. `Goal`, `Audience`, `Message`, `Aa` and the three input headings use a complete opacity fade while the cards remain at full size. No mask, overflow crop, translation or vertical scale is used to hide that copy.

The critical schedule is defined on integer frames:

| Frame | Action |
|---|---|
| 645–650 / 21.500–21.667s | Complete text fades; all three card rectangles remain fixed. |
| 651–652 / 21.700–21.733s | Text draw calls stop entirely; two frames contain only card geometry. |
| 653–688 / 21.767–22.933s | Pure paper, swatch and footage shapes move and compress into timeline material. |
| 690 onward / 23.000s onward | The selected material opens into playing output; `Ready-to-share content` enters from 23.200s. |

The document now has offset paper layers, a tab, fold corner, checkboxes and editorial rules. Brand inputs use hinged swatches and a type sample; footage has playing frames, perforations and cropping marks. Shared matte panels, slight thickness, restrained contact shadows and consistent strokes give these objects depth without a new 3D dependency.

Editing actions carry the story: the opening rail becomes a message, messages are gathered into a timeline, the studio workspace rearranges into client inputs, and material expands into a moving video. The service chapters retain their distinct jobs: precise trimming for Quick Edit, one-to-many content for Campaign Content Pack, and planned queues within the 20-hour monthly cap. The final filename retires before its physical window folds into the final brand composition.

Formal text keeps the measured-font repair from V4. The earlier cropped descenders came from a fixed Canvas entry-mask bottom of `baseline + 0.24 × fontSize − 8`. Display, Body and Mono now load before measuring or rendering. Final layout uses actual glyph ascent, descent, overhang and padding; the entry mask stops constraining settled words. No global overflow bypass or global font reduction is used.

Service headings remain 85px. Prices use 94px bold lime, and `Proposed price` uses 31px regular type with a clear baseline gap. Small video captions use measured two-line geometry. Preview and export use the same deterministic 30fps frame time; source-video time stays continuous through scene changes.

## Verification and review evidence

`transition-qa.cjs` instruments actual Canvas text draw calls and card rectangles across frames 640–700. It checks complete-opacity retirement, stationary full-size geometry during the fade, a two-frame gap, no internal words during compression, and no translation, scale or glyph clipping of `Message` during its fade. It also checks message-to-timeline and filename-to-brand retirement. This is a live rendering check, not a substitute for reviewing the encoded film.

`text-qa.cjs` checks settled glyph pixels and active masks. `encoded-text-audit.cjs` measures selected crops from the exported MP4. `extract_text_states.py` decodes exact frame numbers for four stages of 46 major text blocks, including the document's `Goal`, `Audience` and `Message`. It also extracts frames 645, 648, 650, 651, 652, 653, 660, 672, 688 and 690 for the critical text-retirement transition. Manifest files record the source movie SHA-256, so evidence can be tied to a specific export.

The resulting evidence is under `output/encoded-review`, `output/encoded-text-audit` and `output/transition-contact.jpg`. Extraction alone is not a visual pass verdict; consult the accompanying review report for the scope of the actual final-MP4 inspection. `check_media.py` separately decodes the complete 2,250-frame movie and verifies delivery properties.

The ZIP includes the complete MP4, offline project, local media and compact review evidence. Full-resolution extracted PNGs are omitted to keep the download small; regenerate them from the included MP4 with `python scripts/extract_text_states.py`. NumPy and Pillow are needed only for the optional media-analysis/contact-sheet tools. The player and renderer need only Node.js, the locked Playwright dependency, Chromium and FFmpeg.
