# Final Final Studio — Business Plan film / typography and motion revision

Complete **75-second** film for **Yiran Wang**, **Media Business & Enterprise**. Delivery is **1920 × 1080**, **30 fps**, **2,250 frames**, H.264/AAC with Rec.709 colour metadata. The canvas has no persistent corner branding, chapter labels, page numbers, timecodes or debug text. The final brand card is static from exactly 72.000 to 75.000 seconds.

## Play

Requires Node.js. From this project directory:

```sh
npm ci --cache /tmp/final-final-v3-npm-cache
npm start
```

Open the served index.html. Its controls, chapters and JSON editor are outside the rendered film. Play starts the original music and action effects; sound can be muted. The HTTP server supports video byte ranges for accurate scrubbing. If port8000 is occupied, run `PORT=8001 npm start`.

The exported film is `output/FinalFinalStudio-BusinessPlan-75s-v4.mp4`. A complete MP4 is also included in the delivery ZIP so the preview download button works after extraction. Preview and movie playback need no external asset or font requests.

## Edit and render

```sh
npm run render
npm run stills
node scripts/check.cjs
python scripts/package_delivery.py
```

Rendering needs FFmpeg and Chromium. Install a browser with `npx playwright install chromium` or point `CHROMIUM_PATH` at a system Chromium. The exact Playwright dependency is locked. The renderer samples the live composition at30fps, seeks the actual product video for each frame, and mixes the provided music/effects master without any speech.

`node render.cjs --range 25:35` renders an optional local inspection segment; the normal render always produces the complete75seconds. The renderer preserves failure exit status and writes FFmpeg logs under output/.

- **config.js**: all principal copy, proposed prices, chapter boundaries, colours and media/sound paths. Service and brand names retain natural capitalization.
- **engine.js**: editable vector/type, mask, video-crop, graphic and input primitives; source-video clocks and simple colour treatment.
- **chapters.js**: author intro, request-to-brand choreography, client inputs, promise, filename and final card. Detailed word/path timing is editable here.
- **services.js**: actual service demonstrations, package quantities, prices, capped monthly planning and project process. Detailed choreography is editable here.
- **index.html**: playable full-film composition, frame slider and configuration editor. Applying JSON changes affects the current preview; save it into config.js to keep changes.
- **assets/beat-map.json**: actual120BPM music beats and action effects with exact time/frame markers. Source audio is generated by scripts/make_audio.py; NumPy is needed only to regenerate it.

The main chapter boundaries in config.js describe the delivery timing. To retime choreography, also update the relevant phase boundaries in chapters.js/services.js and source-video clocks in engine.js, then regenerate the audio/cue map and render again.

## Typography and continuity revision

The earlier cropped descenders came from a fixed-height Canvas entry mask. Its lower edge was `baseline + 0.24 × fontSize − 8`; at29px this ends above the baseline, while the actual font still has6px of descenders. Loaded-font measurements and crops from the old encoded MP4 confirmed the cause.

The updated engine measures actual glyph ascent/descent and horizontal overhangs after all bundled fonts load. Final layout bounds include padding; the controlled entry mask is separate and stops constraining text after entry. Multiline word timing uses a cumulative word index. No global overflow bypass or global font reduction is used.

Service headings remain85px. Prices use94px bold lime, and Proposed price uses31px regular type with a clear baseline gap. Small video captions use measured two-line geometry and frame height so they cannot collide. Stable messages and work items no longer float without purpose.

The same six campaign assets merge into the monthly queue and move back into the body of work. The studio wordmark has one measured layout across its scale change. Product-camera time stays continuous through morphs with zero-velocity turns. The intro leaves before the pain headline enters; the file name leaves before the final wordmark enters. Playback and export use the same30fps frame time.
